# haonote 0.1.4

公开预发布版。

## 更新

- 修复系统关窗请求被其他便签接收的问题。关闭 Explorer 只隐藏资料库，已打开的便签继续保留；关闭一张便签不影响其他窗口。退出整个应用仍使用「退出haonote」。
- 独立便签不占任务栏；Explorer 可从托盘重新打开。
- Explorer 便签列表上方新增卡片 / 列表切换、标题与正文搜索、创建 / 修改时间升降序，以及今天、最近 7 天、最近 30 天筛选。
- 记住显示形式、排序和时间筛选；搜索词不跨启动保留。上述筛选可与侧栏分类组合使用。
- 增加列表筛选和原生多窗口关闭回归测试。

## 下载与升级

- Windows x64：`haonote_0.1.4_x64-setup.exe`
- Ubuntu 24.04 x86_64：`haonote_0.1.4_amd64.deb`
- Linux x86_64：`haonote_0.1.4_amd64.AppImage`

附件 `SHA256SUMS` 可用于校验。Source code 是源码，不是安装包。

升级前建议导出 JSON 备份，通过「退出haonote」正常退出，再安装新版。正式版应用标识和资料库位置不变，沿用原有便签、同步配置与窗口设置；不要删除应用数据。AppImage 用户替换可执行文件即可。

本版仍没有应用内自动更新。未来接入更新需要签名验证、下载失败处理和保存后重启流程；首次安装支持更新的版本仍需手动升级。

## 已知限制

本地验证：前端构建与格式检查通过，11 项界面测试、17 项核心测试通过；Linux 原生回归覆盖多窗口系统关闭、任务栏隐藏和原有编辑操作。Rust Clippy 检查通过。

Windows 安装包未签名，尚需 Windows 实机验收；首次安装可能联网下载 WebView2。Linux 原生自动测试不能替代 Windows / Wayland 验证。GitHub 下载的大陆网络可用性取决于网络环境。手机端、端到端加密和自动更新尚未实现。
