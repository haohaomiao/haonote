# haonote 0.1.7

公开预发布版。修复可能导致已有正文被 Ctrl+Z 撤为空白并同步的数据安全问题，建议旧版用户升级。

## 更新

- 修复打开已有便签后 Ctrl+Z 可撤销整篇加载内容的问题。加载、模式切换及外部更新不再进入编辑撤销记录；载入外部正文时清除旧撤销／重做记录，避免覆盖新版本。
- Ctrl+Z 撤销、Ctrl+Y 重做，保留 Ctrl+Shift+Z；剪切、复制、粘贴沿用 Ctrl+X/C/V。补充排版和源码模式快捷键回归测试。
- 同步基于共同祖先自动合并不同字段及不重叠正文行，保留双方原始版本。同一行、删除与编辑并发、复杂 Markdown 等无法安全判断的情况仍提示冲突。
- 标题栏右键或“…”菜单增加历史版本查看与恢复。恢复创建新版本，不删除历史；保留的是已封存版本，不是逐次按键记录。
- 优化读取：列表及保存只解析当前分支正文；有冲突时才读取该便签历史；同步先比较编号，每轮最多读取 12 条待上传正文。历史按每页 50 条查看。
- 旧数据库首次打开会建立关系索引，不删除原正文或历史，不改变云端同步格式。

## 安装与升级

- Windows x64：`haonote_0.1.7_x64-setup.exe`
- Ubuntu 24.04 x86_64：`haonote_0.1.7_amd64.deb`
- Linux x86_64：`haonote_0.1.7_amd64.AppImage`

先从 Explorer 底部「导出」保存 JSON 完整备份，正常退出旧版再安装新版；不要删除应用数据。若正文此前已经变空，先从备份或历史提取原文，本次修复不会自动恢复已丢失的编辑内容。

建议全部同步设备升级，避免旧版编辑器继续触发撤销缺陷。自动更新仍未启用。Windows 安装包未签名；Windows 实机及真实坚果云多设备验收仍需进行。历史会持续占用空间，本版不自动清理历史。

本地验证：28 项 Rust 测试、23 项浏览器界面测试、生产构建与 Clippy 检查通过。安装包及原生 Linux 回归由 GitHub Actions 验证；请使用附件 SHA256SUMS 校验下载文件。
