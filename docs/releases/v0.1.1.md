# 轻笺 QingNote 0.1.1

简洁、离线优先的 Windows / Linux 桌面便签，支持自有 WebDAV / 坚果云同步。

## 新增

- Markdown 排版直接编辑，支持撤销、任务勾选、列表、表格和代码块。
- 选中文字后右键设置加粗、斜体、下划线；字体和字号收进菜单，不占用日常编辑空间。
- 双击标题栏折叠 / 展开，并恢复原有窗口大小。
- 独立标题、窗口大小、不透明度和原生右键菜单。
- 保留源码入口、自动保存、归档、回收站、备份和同步冲突处理。

## 安装

- Windows x64：`QingNote_0.1.1_x64-setup.exe`
- Ubuntu 24.04 x86_64：`QingNote_0.1.1_amd64.deb`
- Linux x86_64：`QingNote_0.1.1_amd64.AppImage`

Windows 程序未签名；缺少 WebView2 时安装器需要联网下载运行时。Linux 基于 Ubuntu 24.04 构建，其他发行版和 Wayland 尚未全面验证。

## 升级与注意事项

1. 先在旧版导出 JSON 备份，再正常退出程序后安装新版。
2. 正式版沿用原资料库和同步配置。开发版使用独立资料库；开发测试便签不会自动出现在正式版，需要手动导出、导入。
3. 独立标题参与同步，所有同步设备需升级到支持标题的版本；旧客户端会拒绝新字段。
4. 新便签默认排版编辑，已有便签保留其模式偏好。
5. 不支持的复杂 Markdown 保留源码并提示切换，不静默删除；实际编辑会规范化部分标记与空白。

## 验证范围

15 项核心测试、7 项浏览器测试及 Linux 原生窗口回归通过。Windows 安装包已构建，但尚未实机验收；真实坚果云账号也需要在自己的设备上验证。本版以预发布版本提供，无自动更新服务、移动端或端到端加密。
