# haonote 0.1.6

公开预发布版，增加删除线操作入口，保留 0.1.5 的便签整理及折叠避让功能。

## 更新

- 正文选区右键菜单和文本格式工具中新增「删除线」，再次操作可取消。
- 支持 Ctrl+Shift+S（Mac 键位为 Cmd+Shift+S）；排版编辑与 Markdown 源码模式均可使用。
- 删除线使用 Markdown `~~文字~~` 保存，支持撤销及关闭后重新打开恢复，不改变数据库或同步格式。

## 安装包与升级

- Windows x64：`haonote_0.1.6_x64-setup.exe`
- Ubuntu 24.04 x86_64：`haonote_0.1.6_amd64.deb`
- Linux x86_64：`haonote_0.1.6_amd64.AppImage`

用附件 `SHA256SUMS` 校验安装包。GitHub 的 Source code 是源码，不是安装程序。

建议先导出 JSON 备份，通过菜单「退出haonote」正常退出旧版，再安装新版。不要删除应用数据；原便签与同步设置沿用。AppImage 用户替换可执行文件并保留执行权限。

自动更新仍未启用，请手动下载安装包。Windows 安装包未签名，系统可能提示风险；Windows 原生菜单与快捷键仍需实机验收。没有发布 macOS 或手机安装包。
