# haonote 0.1.5

公开预发布版，主要增加便签窗口整理。

## 更新

- Explorer 列表上方和托盘菜单新增「一键整理」「撤销整理」。
- 整理所有当前可见、未最小化的便签，包含展开与折叠状态；按所在显示器的可用区域分别排列，不改变大小、置顶和折叠状态。
- 空间不足时尽量错位排列，露出标题栏；超大便签不强制缩小，极端拥挤情况下无法保证全部标题可见。
- 撤销恢复本次运行中最近一次整理前的位置，已经关闭的便签不会重新打开。显示器拔掉后尽量保持标题可操作。
- 刚折叠的便签自动避让同屏其他可见便签，只移动当前这一张，不在手动拖动时强制吸附。
- 发布流程恢复普通安装包构建，不需要更新签名密钥，不发布自动更新渠道。安装包缺失或重复时停止发布。

## 下载和升级

- Windows x64：`haonote_0.1.5_x64-setup.exe`
- Ubuntu 24.04 x86_64：`haonote_0.1.5_amd64.deb`
- Linux x86_64：`haonote_0.1.5_amd64.AppImage`

附件 `SHA256SUMS` 提供安装包校验。GitHub 的 Source code 是源码，不是安装程序。

升级前建议导出 JSON 备份，通过菜单「退出haonote」正常退出，再安装新版。不要删除应用数据；已有便签、同步配置和资料库沿用原位置。AppImage 用户替换可执行文件并保留执行权限。

## 范围与限制

自动更新继续搁置，本版仍需手动升级；保留的更新入口在未配置公钥时禁用，不自动下载或安装。字体与字号仍为现有固定选项，本版没有扩展字体选择。

窗口整理已通过布局单元测试及 Linux 原生窗口回归。Windows 多屏、混合 DPI 与 Wayland 环境仍需实机验收；限制程序定位窗口的桌面环境可能不支持。Windows 安装包未签名，系统可能显示安全提示。

不改变便签内容、数据库格式及 WebDAV 同步方式。坚果云桌面客户端自己的通知不由 haonote 控制。
