# haonote 0.1.2

Windows / Linux 桌面便签，本版公开提供安装包，标记为预发布版本。

## 更新

- 正文右键增加剪切、复制、粘贴，支持 Ctrl/Cmd+X/C/V；支持的富文本格式可以保留。
- 排版编辑内拖动选区改为移动，单独一步撤销可恢复原位置；关闭桌面文件拖放接管以支持 Windows HTML 文本拖放。
- 删除多余英文装饰文案、重复标识及无用样式。
- 「导入旧便签」可只读导入 Simple Sticky Notes 的 `.db` 备份：标题、纯文本、近似颜色和时间；来源回收站内容仍进入回收站。重复导入跳过已迁入便签，不覆盖本地修改。
- 修复 Windows GitHub Actions 换行符导致的格式检查失败；版本标签构建完成后自动公开发布安装包。

## 下载与安装

- Windows x64：`haonote_0.1.2_x64-setup.exe`
- Ubuntu 24.04 x86_64：`haonote_0.1.2_amd64.deb`
- Linux x86_64：`haonote_0.1.2_amd64.AppImage`
- `SHA256SUMS` 为本次 CI 安装包的校验清单。GitHub 自动提供的 Source code 压缩包是源码，不是安装包。

Ubuntu 下载后执行 `sudo apt install ./haonote_0.1.2_amd64.deb`。AppImage 需添加可执行权限，其他发行版和 Wayland 尚未全面验证。Windows 程序未签名，缺少 WebView2 时安装器需联网下载运行时。

## 升级与导入

先导出 JSON 备份、退出旧版，再安装更新。沿用已有正式版资料库及同步配置；开发版资料库独立。若仍使用旧名 QingNote，Windows 请先卸载旧程序但保留应用数据，再安装 haonote；Linux deb 会替换旧包。

Simple Sticky Notes 请先通过其 Database → Backup 生成备份，或完全退出后复制 Notes.db，再点击 haonote 列表底部「导入旧便签」。原 DB 不修改、不上传到开发者仓库；导入后便签会按自己的 haonote 同步设置同步。

导入是一次性迁移，不是双向同步。暂不迁移 RTF 格式、图片、闹钟、分组或窗口布局，请保留原备份。来源日期无时区，按原墙上时间标记为 UTC，显示可能有时区偏差。正文按 Markdown 显示，查看原文可切换源码。单个备份最多 32 MB、10000 条便签，单条正文最多 128 KB，不支持或无效记录会取消整批导入。

## 验证与限制

17 项核心测试、9 项浏览器测试通过；本地示例数据库在临时资料库中验证只读导入和重复导入。Linux 原生回归包含剪贴板菜单及原有窗口操作。个人示例数据库不包含在源码、测试或安装包中。

Windows 实机、真实坚果云双设备同步仍需验收。没有移动端、端到端加密或自动更新功能。
