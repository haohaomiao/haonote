# haonote 0.1.3

公开预发布版，包含近期全部改动。0.1.2 因界面测试偶发失败未公开发布；本版修复测试选区准备的时序问题，不覆盖旧标签。

## 更新

- 正文右键增加剪切、复制、粘贴，支持 Ctrl/Cmd+X/C/V；保留支持的富文本格式。
- 排版编辑内拖动选区默认移动，单步撤销恢复原位置；启用 Windows 编辑器的 HTML 文本拖放。
- 清理英文装饰文案、重复标识和无用样式。
- 「导入旧便签」支持 Simple Sticky Notes `.db` 备份：标题、纯文本、近似颜色和时间；删除记录进入回收站。重复导入不覆盖已有便签。
- 修复 Windows CI 换行符检查，稳定拖放测试，增加可直接查看的 GitHub 测试错误摘要。通过检查后自动公开发布安装包。

## 安装包

- Windows x64：`haonote_0.1.3_x64-setup.exe`
- Ubuntu 24.04 x86_64：`haonote_0.1.3_amd64.deb`
- Linux x86_64：`haonote_0.1.3_amd64.AppImage`

下载后可用附件 `SHA256SUMS` 校验。GitHub 自动提供的 Source code 是源码，不是安装程序。Ubuntu 执行 `sudo apt install ./haonote_0.1.3_amd64.deb`；AppImage 需要添加可执行权限。Windows 未签名，缺少 WebView2 时安装器需联网下载。

## 升级与导入

先导出 JSON 备份并退出旧版，再安装新版；沿用正式版资料库和同步设置。开发版资料库独立。旧名 QingNote 的 Windows 用户请先卸载旧程序但保留应用数据，Linux deb 会替换旧包。

在 Simple Sticky Notes 中通过 Database → Backup 生成 `.db` 备份，再点击 haonote 列表底部「导入旧便签」。也可以完全退出来源软件后复制 Notes.db。源文件只读，不会上传到开发者仓库；导入的便签按自己的 haonote 云同步配置同步。

导入是一次性迁移，不是双向同步。暂不迁移 RTF 格式、图片、闹钟、分组或窗口布局，请保留源备份。源日期没有时区，按原墙上时间标记为 UTC，可能存在显示时差。正文按 Markdown 显示，原样查看可切换源码。限制为 32 MB、10000 条便签、单条正文 128 KB；遇到不支持或无效记录时整批取消。

## 验证范围

17 项核心测试通过，9 项界面用例连续 5 轮（45 次）通过。示例数据库在临时资料库验证了只读导入、重复导入及原文件不变；个人数据库不包含在发布文件中。Linux 原生回归覆盖剪贴板菜单与原有窗口操作。

仍需 Windows 实机、真实坚果云双设备及其他 Linux / Wayland 环境验收。没有移动端、端到端加密或自动更新功能。
