# 0.1.0 发布候选记录

这是可安装、可继续验收的桌面候选版，不是已经完成所有平台和真实云服务验收的正式稳定版。未上传应用商店或 GitHub Release。

## 安装包

以下路径相对于项目根目录：

| 平台 | 安装包 | 验证范围 |
| --- | --- | --- |
| Ubuntu 24.04 x86_64 | `target/release/bundle/deb/QingNote_0.1.0_amd64.deb` | Linux 发布程序通过原生自动化测试 |
| Linux x86_64 | `target/release/bundle/appimage/QingNote_0.1.0_amd64.AppImage` | 已打包；其他发行版、Wayland 尚未验证 |
| Windows x64 | `target/x86_64-pc-windows-msvc/release/bundle/nsis/QingNote_0.1.0_x64-setup.exe` | 已交叉编译和打包，尚未 Windows 实机运行 |

Ubuntu 安装：

```sh
sudo apt install ./target/release/bundle/deb/QingNote_0.1.0_amd64.deb
```

安装包校验值见 [SHA256SUMS](SHA256SUMS)，在项目根目录运行 `sha256sum --check docs/SHA256SUMS` 可核对本次构建产物。

AppImage 需要可执行权限和运行环境支持。基于 Ubuntu 24.04 构建，不承诺旧版 Linux 兼容。

Windows 安装包未签名，可能触发系统信誉提示。缺少 WebView2 时安装程序需要联网下载微软运行时；离线或无法连接微软下载服务的机器须预先安装 WebView2。当前没有自动更新服务。

## 发布前仍需人工验收

1. 在设置中填写自己的坚果云邮箱和第三方应用密码。先使用专门的测试目录和非敏感测试便签；凭据不需要发给开发者。
2. 在 Windows 实机检查安装、中文输入法、托盘、置顶、开机启动、退出和卸载。
3. 两台真实设备测试在线同步、离线编辑后重连、同一便签并发编辑和删除恢复。
4. 在实际桌面环境验证系统凭据库和开机启动；虚拟桌面测试不覆盖这些系统集成。

暂未实现手机端、端到端加密、远端历史压缩和自动更新。WebDAV 账号额度及网络质量由服务商和本地网络决定；程序没有内置海外账号服务器，但不能保证任何地区永远可连接。

## 构建说明

常规构建命令及 GitHub Actions 流程见 README。此环境没有 Windows 主机，本次使用 Rust MSVC 目标、cargo-xwin 和微软 SDK 交叉编译 Windows 程序，再用 NSIS 编译 Tauri 生成的安装脚本。未改动应用代码以适配交叉打包。正式发布建议采用仓库内 Windows 原生 CI 构建并完成实机验收。
